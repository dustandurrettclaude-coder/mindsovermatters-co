## The listings

For each of the three, the flow is: Listings → Add a listing → **Digital** (instant
download) → upload the zip → upload the listing image as the first photo → title →
description → price → quantity 999 → tags → publish.

Notes that apply to all three:
- Upload the ZIP, not the individual PDFs. Etsy caps how many files one listing can
  carry, and each of these has six to nine files inside.
- These are **digital, instant download**. Nothing ships. Make sure the listing type is
  set to digital before uploading, or Etsy will ask for shipping details.
- Quantity 999 so it never sells out.
- Category: Etsy's own suggestion for "printable" or "templates" is usually right. Read
  it to him rather than guessing for him.
- He can add more photos later. One good image is enough to publish.

## Two things to tell him honestly

1. **These may not sell.** Each listing is an experiment with a written kill rule: zero
   sales in 30 days from the listing date and the product goes to the graveyard with a
   failure report. That is the system working, not a loss. The comps that justified
   building these had 260 to 8,300 reviews on a single listing, but a brand-new listing
   with no reviews starts at the bottom of search.
2. **Do not let him spend money to fix slow sales.** No Etsy Ads, no promoted listings,
   no paid tools. If sales are slow the answer is better titles and tags, or the kill
   rule. That decision goes back to the Claude Code session, not to a credit card.
