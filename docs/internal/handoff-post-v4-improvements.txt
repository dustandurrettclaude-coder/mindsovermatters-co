D. /close STAYS — AUTOMATIC CAPTURE GOES UNDERNEATH IT (floor and ceiling)
  Evidence from the scorecard: claude-mem is memory 9 / session 4 (automatic capture, no
  routine). MOM is memory 6 / session 9 (routine, no automatic capture). They are different
  things. Replacing /close with automation trades toward claude-mem's profile. Do not.
  - FLOOR = automatic capture. Its ONLY job is killing "forgot to close, lost the session".
      session record / memos / skills_used -> written as you go (Claude Code: Stop/SessionEnd
      hook; chat surfaces: incremental writes + reap-abandoned-sessions as the path)
      mark closed / heartbeat / lock / ptr  -> the reaper, not the user
  - CEILING = /close, unchanged in purpose. It PROMOTES the automatic record into
      understanding: wrap (lessons with the user present), curated memory, the handoff
      carrying intent and next action, the pending-confirmations tick moment, the
      governor/self-verify honesty checkpoint. None of these are automatable without losing
      what earns the session-routine 9.
  - What changes in /close: only the fear. It stops being mandatory-or-lose-everything.
    Lite becomes near-instant because the record already exists and close just promotes it.
  - Analogue: Perplexity threads auto-save (floor); Pages is the deliberate act that makes
    a durable artifact (ceiling). Same shape.
  - Product line: "It remembers everything on its own. When you close, it understands the
    session." Moves memory AND session, instead of trading one for the other.
  - Caveat still holds: Cowork/claude.ai have no hooks — score the floor per surface.
